# Erwhan Le Coueffec — Portfolio

Mobile-first R&D engineering portfolio for Erwhan Le Coueffec.

## Stack

- React 19
- Vite 8
- Tailwind CSS 4
- Motion
- React Router
- GitHub Pages + GitHub Actions

## First pass

Implemented:

- Dark, cyan, mobile-first visual direction
- Fixed responsive navigation + hamburger menu
- EN / FR / DE language selector with persisted preference
- Hero, About, R&D targets, Projects, Experience, Education, Skills, Languages and Contact
- HoloScan technical case study
- Camera Design of Experiments technical case study
- Reduced-motion accessibility support
- GitHub Pages SPA fallback
- Pull-request lint/build validation and main-branch deployment workflow

Still to add / refine:

- Final project photographs and plots
- Approved company / school logo assets
- LinkedIn URL
- Final French and English one-page PDF CVs
- Final German technical review (some detailed sections intentionally inherit English in this first pass)
